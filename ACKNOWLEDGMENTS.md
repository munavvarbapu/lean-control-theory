# Acknowledgments

This project uses Lean 4 and mathlib. In particular, mathlib supplies
linear maps and subspaces, Cayley--Hamilton, dual-space separation,
existence of eigenvectors over algebraically closed fields, and real
calculus. The project-specific control-theory statements are built on
those results.

- [Lean 4](https://github.com/leanprover/lean4)
- [mathlib](https://github.com/leanprover-community/mathlib4)
- [Mathematics in Lean](https://leanprover-community.github.io/mathematics_in_lean/)

AI assistance was used to develop the code and documentation. The build
and axiom report record what Lean checked.
